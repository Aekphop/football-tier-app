# ⚽ Football / Player Skills Tier List & Voting Web App

เว็บแอปพลิเคชันจัดอันดับ **Tier List** ทักษะฟุตบอลจากการโหวตหาค่าเฉลี่ย 7 หมวด 36 ข้อย่อย (คะแนนเต็ม 180) พร้อมระบบสิทธิ์ผู้ดูแลระบบ (Admin) ควบคุมเวลา/ล็อคโหวต, ล็อคไม่ให้โหวตตัวเอง, ล็อคผลคะแนนหลังส่ง, และระบบสร้างรูปภาพ Tier List (PNG) คุณภาพสูง

---

## 🌟 ฟีเจอร์หลักในระบบ (Features)

### 1. ระบบยืนยันตัวตน & แยกสิทธิ์ (Authentication & Roles)
- **General User (คนทั่วไป)**: เข้ามาโหวตให้คะแนนผู้เล่น 1-5 ในแต่ละข้อ และดูผลคะแนน Tier List / Radar Chart
- **Admin ("ฉัน")**: ปรับแต่งเว็บแอป, กำหนดวัน-เวลาเริ่ม/สิ้นสุดการโหวต, สั่งล็อค/ปลดล็อคโหวตทันที, เพิ่ม/ลบ/แก้ไขรายชื่อผู้เล่น, และรีเซ็ตระบบ
- **Dev Account Switcher**: สลับบัญชีทดสอบได้ทันทีในคลิกเดียว

### 2. ระบบควบคุมเวลาและล็อคโหวต (Timer & Lock System)
- ตั้งวันและเวลาเริ่มโหวต (Start Time) และเวลาปิดรับโหวต (Deadline)
- ปุ่มสวิตช์ Lock/Unlock โหวตแบบ Manual ได้ทันทีโดย Admin
- ตัวนับเวลาถอยหลัง Real-time Countdown บนหน้าแรกและหน้าโหวต

### 3. ระบบกติกาความโปร่งใส (Anti-Cheat & Fairness Rules)
- **ล็อคไม่ให้โหวตตัวเอง (Prevent Self-Voting)**: ผู้เล่นไม่สามารถประเมินผลคะแนนให้ตนเองได้
- **ล็อคผลโหวตถาวรหลังกดส่ง (No Edits After Submit)**: เมื่อกดยืนยันการส่งผลโหวตแล้ว ระบบจะล็อคผลถาวร ไม่สามารถกลับมาแก้ไขคะแนนได้

### 4. ระบบการโหวต 7 หมวดหลัก 36 ข้อย่อย (Voting 1-5 Points)
- ปุ่มกดคะแนนเป็นวงกลมตัวเลข 1, 2, 3, 4, 5 พร้อมคำอธิบายภาษาไทยและอังกฤษ:
  - **1 = แย่** (ต่ำกว่ามาตรฐานมาก)
  - **2 = ปรับปรุง** (ยังต้องฝึกฝนเพิ่มเติม)
  - **3 = พอใช้** (อยู่ในเกณฑ์มาตรฐานทั่วไป)
  - **4 = ดี** (ทำได้ดี โดดเด่นกว่าค่าเฉลี่ย)
  - **5 = ดีมาก** (ยอดเยี่ยม ระดับท็อปคลาส)
- โครงสร้าง 7 หมวด 36 ข้อ:
  1. **ทักษะพื้นฐาน (BASIC SKILLS)** - 6 ข้อ
  2. **ความสามารถทางกายภาพ (PHYSICAL)** - 6 ข้อ
  3. **ความเข้าใจเกม (GAME UNDERSTANDING)** - 6 ข้อ
  4. **จิตใจและทัศนคติ (MENTALITY)** - 6 ข้อ
  5. **การเล่นร่วมกับทีม (TEAM PLAY)** - 5 ข้อ
  6. **ผลงานในเกม (MATCH PERFORMANCE)** - 5 ข้อ
  7. **การใช้เท้า (FOOTWORK)** - 2 ข้อ

### 5. การคำนวณคะแนน & จัด Tier List อัตโนมัติ
- คำนวณค่าเฉลี่ย ($\text{Average}$) ของแต่ละข้อย่อยจากผู้โหวตทั้งหมด
- รวมผลค่าเฉลี่ยทั้ง 36 ข้อเป็นคะแนนรวม ($\text{Total Score}$ เต็ม 180 คะแนน)
- เกณฑ์การจัด Tier:
  - **Tier S**: 136 – 180 คะแนน (คะแนนสูงสุดอยู่ซ้ายสุด)
  - **Tier A**: 91 – 135 คะแนน
  - **Tier B**: 46 – 90 คะแนน
  - **Tier C**: 0 – 45 คะแนน
- กราฟใยแมงมุม (Radar / Spider Chart) แสดงจุดเด่น-จุดด้อย 7 ด้านของผู้เล่นแต่ละคน

### 6. ระบบสร้างรูปภาพ Tier List (High-DPI PNG Exporter)
- สร้างภาพ Tier List สวยงามคมชัดสูง (2K/Full HD)
- แสดงชื่อ, รูปโปรไฟล์, ตำแหน่ง, คะแนนรวม, และผู้ร่วมโหวต
- ปุ่มคลิกเดียวเพื่อบันทึกและดาวน์โหลดไฟล์ `.png` ไปแชร์ลงโซเชียลได้ทันที

## 🚀 วิธีการติดตั้งและเริ่มใช้งาน (Getting Started)

### ขั้นตอนที่ 1: ติดตั้ง Dependencies
เปิด Terminal ในโฟลเดอร์โปรเจกต์ `c:\web app tier` แล้วรัน:
```bash
npm install
```

### ขั้นตอนที่ 2: เริ่มต้นรันเซิร์ฟเวอร์
```bash
npm run dev
```

เปิดบราวเซอร์ไปที่: **`http://localhost:3000`**

---

## ⚙️ การตั้งค่าระบบ (Configuration)

สามารถแก้ไขไฟล์ `.env` เพื่อระบุอีเมลผู้ดูแลระบบของคุณ:
```env
ADMIN_EMAILS="admin@gmail.com,your-real-email@gmail.com"
```
เมื่อคุณล็อกอินด้วยอีเมลนี้ ระบบจะมอบสิทธิ์ **Admin (ฉัน)** ให้อัตโนมัติทันที
